# 픽셀 패닉 런

탑다운 2D 픽셀 인디게임 스타일로 다시 만든 혈압마라톤형 로컬 프로토타입입니다.

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://127.0.0.1:5174](http://127.0.0.1:5174)를 여세요.

## 현재 구현 범위

- 픽셀 아트 대기실과 탑다운 운동장 트랙
- 체크포인트를 순서대로 통과하는 1랩 구조
- 회전봉, 랜덤 구덩이, 역방향 점프대와 낙하/체공 모션
- 마우스 조준선·크로스헤어와 조준 펄스
- 별도 스킬 연습장과 이동하는 테스트 캐릭터 4명
- 숫자 키 `1`~`7` 스킬, `R` 랜덤 스킬 테스트

## 조작

| 입력 | 동작 |
| --- | --- |
| `WASD` 또는 방향키 | 이동 |
| 마우스 | 조준 |
| 좌클릭 | 조준 펄스 |
| `1` | 근거리 밀치기 |
| `2` | 3회 충전 돌진 |
| `3` | 질주 |
| `4` | 사거리 그랩 |
| `5` | 최대 5개 분신 |
| `6` | 범위 슬로우탄 |
| `7` | 2초 수면총 |
| `R` | 사용할 수 있는 스킬 중 랜덤 발동 |

게임 화면 오른쪽의 **스킬 연습장 이동** 버튼으로 테스트 캐릭터가 있는 연습장에 들어갈 수 있습니다.

## 검증

```bash
npm run check
npm run build
```

현재는 로컬 단일 플레이 검증용이며, 멀티플레이 동기화는 아직 포함하지 않습니다.
